## Data Types

| Data Type | Description |
|---|---|
| int | Integer numbers |
| float | Floating-point numbers |
| double | Double-precision floating-point numbers |
| char | A single character |
| bool | True or false value |
| void | No value |
## Format Specifiers

| Format Specifier | Description |
|---|---|
| %d | Decimal integer |
| %u | Unsigned integer |
| %o | Octal integer |
| %x | Hexadecimal lowercase |
| %X | Hexadecimal uppercase |
| %f | Floating-point value |
| %e | Scientific notation |
| %c | Character |
| %s | String |
| %ld | Long integer |
## Input and Output Functions

- `scanf()` → Used to take formatted input from the user.
- `printf()` → Used to display formatted output.
- `getchar()` → Used to input one character.
- `putchar()` → Used to output one character.
- `fgets()` → Used to input a string.
- `puts()` → Used to output a string.
- ## Escape Sequences

| Escape Sequence | Meaning | Example |
|---|---|---|
| `\n` | New line | `printf("Hello\nWorld");` |
| `\t` | Horizontal tab | `printf("Hello\tWorld");` |
| `\\` | Backslash | `printf("\\");` |
| `\"` | Double quotation mark | `printf("\"Hello\"");` |
| `\'` | Single quotation mark | `printf("\'A\'");` |
## Floating-Point Precision

Floating-point precision means the number of digits shown after the decimal point.

For example:
- `%f` can display a floating-point number.
- `%.2f` displays 2 digits after the decimal point.
- `%.4f` displays 4 digits after the decimal point.
- `%.6f` displays 6 digits after the decimal point.

Higher precision shows more digits after the decimal point.
